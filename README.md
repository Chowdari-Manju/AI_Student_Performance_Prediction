🎓 AI Student Performance Prediction & Analytics Dashboard

Machine Learning | Data Analytics | Interactive Web Application

📌 Project Overview

The AI Student Performance Prediction & Analytics Dashboard is a Python-based machine learning application designed to estimate student final marks using academic indicators such as study hours, attendance, assignment scores, and previous marks.

The project combines predictive analytics with interactive visualizations to explore academic performance patterns and provide basic recommendations for improvement.

🌐 Live Demo

Try the application here:
https://aistudentperformanceprediction-wzeo6ht6brstz97ppgfijx.streamlit.app/

✨ Key Features

- Student Performance Prediction: Estimates final marks using a Random Forest Regression model.
- Interactive Analytics Dashboard: Displays academic statistics through charts and KPI cards.
- Performance Analysis: Explores mark distributions and relationships between study hours and academic results.
- Performance Categorization: Groups predicted marks into Excellent, Average, and Needs Improvement categories.
- Academic Recommendations: Provides basic suggestions based on selected student details.
- Interactive User Interface: Allows users to enter student information and view prediction results.

📊 Dataset Description

The project uses 500 synthetically generated student records for demonstration and model development.

The dataset includes:

- Daily study hours
- Attendance percentage
- Assignment scores
- Previous examination marks
- Final marks

The dataset is generated for educational purposes and does not represent actual student records.

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/Chowdari-Manju/AI-Student-Performance-Prediction.git
cd AI-Student-Performance-Prediction


2. Install dependencies

pip install -r requirements.txt

3. Run the application

streamlit run app.py

The dashboard will open in your browser.

🚀 Project Workflow

1. Generate and prepare the student dataset.
2. Select academic features for model training.
3. Train a Random Forest Regression model.
4. Generate predicted final marks.
5. Visualize academic performance using interactive charts.
6. Display prediction results and basic recommendations through Streamlit.
